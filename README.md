# fire-calc — 자유의 불꽃

앱인토스에서 운영하는 파이어(FIRE)족을 위한 계산기 미니앱이에요.
목표 자산과 FIRE 나이를 계산하고, 장작(투자금)을 넣으며 단계별 불꽃을 키워 가는 서비스예요.

- 앱 이름: 자유의 불꽃 / appName: `firegroup` (콘솔 등록값, 변경 불가)
- 스택: React 18 · TypeScript · Vite · TDS Mobile · `@apps-in-toss/web-framework` · Vitest
- 서버 없음. 모든 데이터는 기기에 저장돼요.

## 실행

```bash
npm install
npm run dev          # 로컬 개발 서버
npm run test         # vitest
npm run typecheck    # tsc -b
npm run lint         # oxlint
npm run build        # 타입 체크 + 빌드 + firegroup.ait 생성
```

- 앱인토스에 올릴 파일은 `build` 후 프로젝트 루트에 생기는 `firegroup.ait`예요(git에는 올리지 않아요).
- 콘솔에서 직접 업로드하거나, API 키를 `npx ait token add`로 저장한 뒤 `npm run deploy`로 올려요.
- 개발 서버에서만 `/dev/flames`로 단계별 건물 불꽃을 한눈에 볼 수 있어요.

## 계산 규칙

- 목표 자산 = 월 생활비 × 12 ÷ 안전 인출률(4%)
- 월 복리: 월수익률 = (1 + 연수익률)^(1/12) − 1, 월말 적립, 최대 1,200개월(100년)
- 투자성향별 연수익률: 보수형 3% · 평균형 5% · 공격형 7%
- 단계 판정 (현재 단계 = 만족하는 가장 높은 단계)

| 단계 | 불 | FIRE | 조건 |
| --- | --- | --- | --- |
| 0 | 성냥 | 준비기 | 시작 |
| 1 | 불씨 | Coast FIRE | 목표 자산의 10% 이상 |
| 2 | 촛불 | Semi FIRE | 목표 자산의 30% 이상 |
| 3 | 모닥불 | Barista FIRE | 목표 자산의 60% 이상 |
| 4 | 벽난로 | Lean FIRE | 목표 자산의 70% 이상 |
| 5 | 용광로 | Full FIRE | 목표 자산의 100% 이상 |
| 6 | 불꽃놀이 | Fat FIRE | 목표 자산의 150% 이상 |

- 불꽃 화면의 현재 값 = 시작 금액 + 저축 기록 합계, 나이 = 입력 나이 + 입력 이후 경과 개월 ÷ 12
- 계산은 모두 순수 함수(`src/shared/calc/`)에 있고 `npm run test`로 검증해요.

## 데이터 저장

## 수정사항

### 2026-10-01 불씨 판정 기준 변경
- 불씨만 "지금 자산을 더 넣지 않아도 60세에 목표에 닿는가"라는 계산식이라 나이·수익률에 따라 필요 금액이 계속 바뀌었어요. 그래서 촛불보다 늦게 달성되거나 필요 비율이 촛불(30%)보다 커지는 경우가 있었어요.
- 불씨도 다른 단계처럼 **목표 자산의 고정 비율(10%)**로 바꿨어요. 이제 모든 단계가 10% → 30% → 60% → 70% → 100% → 150%로 올라가서, 달성 나이도 항상 단계 순서대로 늘어나요.
- 예상 도달 나이와 달성률, 다음 단계 목표 금액, 실험 그래프(불씨 금액선 추가)가 같은 기준을 써요. 아래 이전 기록의 "60세 기준 불씨" 설명은 당시 기준이에요.

### 2026-10-01 결과 화면·용어 정리
- 결과 화면에서 "월 투자금을 늘리면?" 버튼을 없앴어요(실험 페이지의 결과 화면 연동 미리 채우기도 같이 정리했어요).
- "조건 바꿔서 다시 계산"을 위로, 주 버튼을 아래로 옮기고 "불꽃 키우러 가기"를 "파이어 단계 진단하기"로 바꿨어요.
- 불꽃 탭의 "장작" 표현을 "저축"으로 바꿨어요(저축하기, 이번 달 저축 누적 금액 등). 아래 이전 기록의 "장작"은 당시 표현 그대로예요.
- 파이어 단계 목록의 "달성 ✓"를 현재 단계보다 아래인지가 아니라 그 단계 자신의 조건으로 판단하도록 고쳤어요. 불씨는 수익률이 낮거나 나이가 많으면 필요 금액이 촛불보다 커질 수 있는데(예: 보수형 3%, 30세), 이때 촛불을 달성해도 불씨는 달성률과 도달 나이로 표시돼요. 불씨 팝오버에도 이 이유를 적었어요.

### 2026-10-01 화면 개편

**1페이지(메인)**
- 기존 문구는 유지하고 서비스 목적 문장을 추가했어요.
- 버튼은 "시작하기" 하나만 남겼어요. 신규 유저는 입력 화면, 기존 유저는 불꽃 화면으로 바로 가요.

**2페이지(입력)**
- 금액 입력을 만원 단위로 바꿨어요.
- 연수익률 대신 투자성향 선택(보수형 3% · 평균형 5% · 공격형 7%)을 맨 아래에 뒀어요. 기본값은 평균형이에요.
- 안전 인출률은 4%로 고정하고 그 아래에 표시해요.
- 이미 입력한 적이 있으면 지금 값(시작 금액 + 저축 기록, 경과한 나이)으로 채워 줘요.

**4페이지(불꽃 화면)**
- 상단 카드에 현재 나이, FIRE 달성 나이(용광로 도달 시점), 총 저축 금액, 다음 단계 목표 금액을 보여줘요. 다음 단계 목표 금액은 단계를 달성하면 자동으로 그다음 단계 금액으로 바뀌어요. 총 저축 금액 옆 "수정" 버튼으로 지금 모아 둔 총액을 직접 맞출 수 있어요(저축 기록은 유지돼요).
- "불 켜진 회사, 손엔 성냥 한 개비" 같은 직관적이지 않은 문구를 지우고, 단계별 한 줄 설명으로 바꿨어요.
- "오늘 불꽃이 낸 열"을 "이번 달 장작 누적 금액"으로 바꿨어요.
- "이번 달 장작 넣기"를 "장작 넣기"로 바꿨고, 한 달에 여러 번 넣을 수 있어요.
- "불꽃 사다리"를 "파이어 단계"로 바꿨어요.
- i 팝오버의 "일의 의미"를 단계별 상세 의미("이 단계의 의미")로 바꿨어요.
- 파이어 단계마다 필요한 목표 자산 비율(%)을 배지로 보여주고, i 팝오버에는 필요 금액을 넣었어요. 불씨는 지금 나이와 수익률로 "60세에 목표에 닿는 데 필요한 비율"을 계산해요.
- 각 단계에 "달성률"(지금 내 자산 ÷ 그 단계에 필요한 금액)과 진행 바를 추가했어요. 이미 넘은 단계는 100%예요.

**불 키우기 실험**
- 새 페이지(`/experiment`)로 분리했어요. "장작·바람·방" 설명은 없애고 "지금 계획(A)과 바꾼 값(B)의 시뮬레이션 비교"라고 적었어요.
- 선택 칩을 입력창으로 바꿨어요(총 저축 금액, 매월 투자금, 은퇴 후 월 생활비, 예상 연수익률). 기존 값이 미리 채워져 있고, A는 기존값·B는 실험값이에요.
- 결과 화면의 "월 50만 원 더 투자하면?" 카드를 누르면 매월 투자금 B 값이 미리 채워진 채로 열려요.
- "단계별 불꽃이 켜지는 나이" 그래프를 x축 나이 · y축 금액의 곡선 그래프로 다시 만들었어요. 기존값(A, 파랑)과 실험값(B, 주황) 곡선을 겹쳐 그리고, 단계별 금액선과 곡선이 만나는 지점에 단계 번호(1 불씨 ~ 6 불꽃놀이)를 표시해요. 그래프를 누르면 나이별 A/B 예상 금액이 나오고, 아래 표에서 단계별 정확한 나이와 A 대비 차이를 볼 수 있어요. 생활비를 바꿔 목표 자산이 달라지면 B 기준선이 주황 점선으로 따로 나와요.
- "실험값(B)을 내 계획으로 적용" 버튼을 추가했어요. 누르면 바뀌는 항목을 확인한 뒤 실험값이 실제 계획으로 저장돼요. 지금 총 저축 금액이 새 시작 금액이 되고 장작 기록은 초기화돼요. 연수익률은 입력한 값 그대로 저장되지만, 입력 화면에서는 가장 가까운 투자성향으로 표시돼요.

**데이터**
- 장작은 "그 달 총자산"이 아니라 "넣은 금액" 기록으로 바뀌었어요. 현재 자산 = 시작 금액 + 넣은 장작 합계예요(장작에 수익률은 따로 붙이지 않아요).
- 조건을 다시 입력하면 입력한 자산이 새 시작 금액이 되고 장작 기록은 비워져요.
- 저장 데이터를 v2로 올렸고, 이전 사용자의 마지막 총자산 기록은 새 시작 금액으로, 인출률은 4%로, 수익률은 가까운 투자성향 값으로 자동 이전돼요.
- 기본 투자성향이 평균형(5%)이라 기본 입력의 FIRE 나이가 만 49세 4개월(7%)에서 만 52세 9개월로 바뀌었어요.
- 테스트를 30개로 늘렸어요(장작 합계, 이번 달 누적, 데이터 이전 포함).
